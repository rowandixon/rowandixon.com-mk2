S3

Mesh Home Speaker System

Portfolio/S3

S3 is a home speaker system for people who want a minimalist, premium home audio experience. Rather than relying on wireless communication, the system uses the home's internal power cabling to minimise cost and latency. Each module is machined from a billet of aluminium with precision-drilled holes that let audio pass from the internal 40mm drivers — the S+ module adds a 20mm tweeter. Room assignment is set via a pair button and app; other features include a tempered glass face plate, a glowing status indicator, machined ventilation slots, and a modular design for easy maintenance and recyclability.
